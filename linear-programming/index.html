02. Понять за две минуты

Задача из лекции №7

1

Выбираем неизвестные

x₁ — сколько выпустить продукции П₁.
x₂ — сколько выпустить продукции П₂.

2

Записываем цель

Одна П₁ приносит 2, а одна П₂ — 3 условных единицы прибыли. Значит, хотим сделать Z = 2x₁ + 3x₂ как можно больше.

3

Соблюдаем ограничения

Запас сырья, станков и времени конечен. На графике голубая область показывает все возможные планы. Лучшая точка — одна из её вершин.

Математическая запись задачи из лекции

Z = 2x₁ + 3x₂ → max
x₁ + 3x₂ ≤ 18
2x₁ + x₂ ≤ 16
x₂ ≤ 5
3x₁ ≤ 21
x₁ ≥ 0, x₂ ≥ 0

В точке (6; 4) первое и второе ограничения выполняются как равенства. Прибыль составляет 24. Третий и четвёртый ресурсы имеют остатки 1 и 3.

Как приводят к канонической форме?

К каждому «≤» добавляют неотрицательный остаток sᵢ. Тогда вместо неравенств получаются равенства.

x₁ + 3x₂ + s₁ = 18
2x₁ + x₂ + s₂ = 16
x₂ + s₃ = 5
3x₁ + s₄ = 21
s₁, s₂, s₃, s₄ ≥ 0

При x₁ = 6, x₂ = 4 остатки: s₁ = 0, s₂ = 0, s₃ = 1, s₄ = 3.

Готовимся к вопросам

Что такое линейное программирование?

Метод поиска максимума или минимума линейной функции, когда на переменные наложены линейные ограничения.

Что такое целевая функция?

Формула, значение которой мы хотим улучшить. У нас Z = 2x₁ + 3x₂ — прибыль, которую нужно максимизировать.

Что такое ОДР?

Область допустимых решений: все сочетания x₁ и x₂, которые удовлетворяют одновременно всем ограничениям. На графике она закрашена.

В чём смысл графического метода?

Чертим границы ограничений, находим допустимую область, двигаем линию одинакового значения прибыли и получаем лучшую вершину.

Чем формы задачи отличаются?

Общая форма допускает разные знаки; стандартная для максимума обычно записана через «≤»; каноническая содержит равенства и неотрицательные переменные.

Какие бывают особые случаи?

Один лучший план; много одинаково лучших планов; невозможные совместно ограничения (нет решений); либо прибыль может расти без границы.

Что такое градиент и линия уровня?

Градиент — направление роста целевой функции, для Z = 2x₁ + 3x₂ это вектор (2; 3). Линия уровня — прямая 2x₁ + 3x₂ = h с одной и той же прибылью h.
